THE IDEA FROM LOGIC GATES TO CRC

XOR does the dividing.
CRC checks the message.

Together, these ideas let a receiver check whether data changed on its way across a network.

01 / THE OPERATION

XOR compares bits

Compare two bits at a time: matching bits produce 0; different bits produce 1. There are no carries or borrows, so XOR works neatly in binary division.

1011 ⊕ 1101 0110
Same → 0   Different → 1
02 / THE CHECK

CRC checks a message

The sender appends zeroes, divides the bits by an agreed generator using XOR, then appends the remainder to the message. The receiver divides the received codeword by the same generator: a zero remainder means it passes this check.

03 / THE HARDWARE

Modulo-2 division in a circuit

This CRC-4 circuit divides a serial bit stream using XOR gates and a four-bit shift register. Each clock feeds in one bit; the register shifts and the feedback XORs apply the generator polynomial, all directly in hardware rather than as a software loop.

For generator 10011 (x⁴ + x + 1), send the message bits followed by four zeroes. Starting from 0000, the register then contains the CRC remainder.

CRC-4 MODULO-2 DIVIDER GENERATOR 10011

A CRC is an error-detection check, not encryption or error correction. A passing check makes accidental corruption unlikely, but cannot prove that data is authentic or unchanged.

The selector applies each CRC standard's polynomial and its initialization, reflection, and final-XOR settings. Unlike simple parity, these CRCs detect every single-bit error and every burst up to the polynomial degree (8, 16, or 32 bits). No fixed-size CRC detects every possible multi-bit error: some longer error patterns can produce the same checksum. CRCs detect errors; they do not correct them.
